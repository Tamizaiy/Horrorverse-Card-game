HORRORVERSE — Alpha 2.2 Multiplayer LAN

Extraia o ZIP inteiro e abra index.html para jogar contra CPU ou no mesmo computador.

NOVA TERCEIRA OPÇÃO: MULTIPLAYER LAN
Para jogar em dois computadores pelo site do Netlify, mantenha o servidor local rodando em um computador da rede. No Windows, use Iniciar-LAN.bat (precisa de Node.js 22 ou superior).

O passo a passo completo está em README-LAN.md.

A pasta contém todos os arquivos do jogo, o servidor local e netlify.toml para publicar o site. O servidor valida as ações, oculta mãos/montes e pausa o duelo durante desconexões.

A conexão do site HTTPS à rede local depende das permissões e da compatibilidade do navegador. Se houver bloqueio, o mesmo jogo está disponível pelo endereço HTTP local mostrado pelo servidor.
